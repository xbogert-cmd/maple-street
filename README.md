# Maple Street

1984. To the neighbours you are the quiet new janitor at the defence plant. The Centre knows you by
a number. Learn the street, do the work, and do not be noticed.

A Project Zomboid-style sandbox with no zombies: the danger is being seen.

## Play
Double-click **Maple Street** on the Desktop, or:

```bash
godot --path "/Users/alexanderbogert/sleeper agent game"
```

| Key | Action |
|---|---|
| W A S D | Move (relative to the screen) |
| Shift | Run (loud) |
| C | Sneak on/off (quiet, harder to see, slow) |
| E, R, T | The actions shown at the bottom of the screen |
| F | Force: knock out, kill |
| N or Tab | Notebook: orders, neighbours, journal |
| I | Pockets |
| Pinch, or - and = | Zoom |
| Esc | Pause and controls |

The game saves only when you sleep in your own bed. Arrest ends that agent for good.

Built with Godot 4.7.1. Design: `docs/superpowers/specs/`. Status: `docs/report.md`.
